# Avari Glow for Orca

A dark Orca theme with a matching terminal palette. Cool blue surfaces meet warm accents and a soft glow.

![Avari Glow interface detail](https://raw.githubusercontent.com/OstKost/orca-avari-glow-theme/main/docs/images/orca-header.png)

Install **Avari Glow** from Orca's Plugins settings, then select Avari Glow separately for the application and terminal themes. Requires Orca 1.4.246 or later.

For optional interface tweaks, installation instructions and source, see the [Avari Glow project and tweak utility](https://github.com/OstKost/orca-avari-glow-theme#дополнительные-твики). The utility is separate from this theme plugin; it modifies the installed Orca application and is not installed by the plugin.

Inspired by a concept by @SIREN.UIX. This is an independent project and is not affiliated with Orca.
